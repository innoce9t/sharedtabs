Settings

Choose what AI agents may use in this browser.

Site permission

Which sites agents can use in shared tabs.

Agents won't ask about sites. If people can message your agent from other apps, this covers their requests too. Agents still only see tabs you share or that they open.

Allowed sites

One per line. example.com includes subdomains. The blocked list still wins.

Blocked sites

Agents can never use these. One per line: example.com includes subdomains, * matches anything, and !example.com makes an exception. The starting list can't cover every bank, so add yours.

File uploads

Files go only to sites you allow, up to 20 MB.

Keys, password files and account tokens are never uploaded. Neither is anything in system or app data folders, unless you list a folder inside them.

Upload folders

One full path per line, such as C:\Users\me\Documents.

What agents can get and do

Choices apply at once. Lists apply when you save.
